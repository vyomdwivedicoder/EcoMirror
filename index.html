AI Usage, Architecture & Methodology

This section documents the AI-assisted development workflow, tool usage, prompt flow, architecture, and human contribution.

AI Tools Used

ChatGPT was used for challenge interpretation, ideation, architecture planning, feature refinement, documentation, README structure, and LinkedIn post drafting.

GitHub Copilot was used for code completion, repetitive JavaScript patterns, UI logic suggestions, function structure, and faster implementation inside the editor.

Why These Tools Were Selected

ChatGPT was selected for reasoning, planning, and documentation. GitHub Copilot was selected to speed up implementation and reduce repetitive coding work.

Prompt Flow

The project started as a basic carbon footprint calculator idea. After reviewing the Challenge 3 explainer session, the direction changed into EcoMirror: an awareness-first platform with a visual carbon world, personalized nudges, analytics, action planning, and social accountability elements.

Human Contribution

The developer handled the final product direction, UI customization, code review, testing, deployment on Vercel, GitHub repository management, and final submission decisions.

Architecture

User Input → Carbon Calculator → Awareness Engine → EcoMirror Visual World → Analytics Dashboard → Personalized Nudges → Weekly Action Plan → LocalStorage.

Challenge Alignment

EcoMirror focuses on awareness instead of only calculation. It translates carbon numbers into visual feedback, real-world meaning, and simple behavior-changing actions.
